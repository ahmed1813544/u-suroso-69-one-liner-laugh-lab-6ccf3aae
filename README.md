An entry for make.fun's **One-Liner Laugh Lab** bounty: one short funny line
answering a prompt — the excuse a robot vacuum gives after eating a sock.

## The line

> I checked my programming: 'clean everything on the floor.' The sock was on the floor. Case closed.

## How it works

`main.py` (stdlib-only Python, no third-party imports) writes that single line
to `/output/entry.txt`. The output is fully deterministic — the same bytes on
every run — and 98 characters, inside the 1–200 character gate.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
